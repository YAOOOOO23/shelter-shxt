# 百日庇护所

像素生存经营与回合战斗游戏原型。探索小溪、森林和遗迹，收集物资，升级装备、模块与庇护所，在一百天内活下去。

## 在线游玩

GitHub Pages 部署完成后，可通过仓库右侧的 Deployments 或 Settings → Pages 查看网址。

## 文件

- `index.html`：游戏页面
- `game.js`：游戏主逻辑
- `events.js`：探索与事件
- `styles.css` / `extras.css`：界面样式

游戏进度保存在浏览器本地存储中。

## 场景与行动反馈

- 四个像素场景：营地、小溪、森林、遗迹；探索演出包含出发、采集或遭遇、回营。
- 人物步行使用8帧动作，按实际位移推进双腿、手臂与披风动作；回程镜像，停步时停止迈步。
- 森林挥斧砍树、遗迹挥镐采矿、小溪蹲下舀水，各使用独立的8帧动作；击打时出现木屑、碎石或水花。
- 建筑随庇护所进化改变，已安装模块在营地中可见；直接点击场景设施可查看实际产出或升级。
- 升华展示进化前后图像与实际属性变化；战斗展示对应敌人、战力构成、门槛削弱与最近的成长。
- 过夜展示补给消耗、设施与核心产出、治疗、灾难损伤；维修修复建筑裂纹。
- 主界面提供真实资源差值、下一场灾难预告、可执行建议和最近12次经历回看。
- 演出支持加速、跳过、减少动态，遵循系统减少动态设置。动画与存档分离，跳过或快速连续操作不会丢失收益。
- 顶部六个独立页面支持浏览器前进、后退与直接链接。切换页面后仅保留当前内容。
- 操作详情、营地设施、规则和庇护所分组支持折叠，并保存展开状态；图鉴每页8项。
- 建造、升级、维修、合成等操作提前显示材料缺口与限制；过夜按来源逐项展示，设施页记录当日实际贡献。
- 战斗由玩家逐回合操作，包含敌人意图、轻击、重击、格挡、诱饵、补给与撤退；支持数字键1–6，提供无损演练，刷新后可继续战斗。
- 角色有独立挥击、格挡与挥锤帧组；建造、拆卸、维修、合成、镶嵌和装备变更均有对应动画反馈。

直接打开 `index.html`，或在项目目录运行 `python -m http.server 8765 --bind 127.0.0.1` 后访问 `http://127.0.0.1:8765`。

新增文件：`experience.js` 管理结果记录、引导和来源结算；`scene.js` 管理场景演出；`gathering.js` 管理工具动作与采集特效；`navigation.js` 管理页面切换与折叠记忆；`experience.css` / `navigation.css` 管理反馈与分页布局；`assets/` 保存本地像素素材与生成提示词。

## 验证

无需安装依赖，使用 Node.js 内置测试工具：

```sh
node --test tests/*.test.cjs
```

测试覆盖升华真实增益、重复收藏、隐藏奖励、生产来源与治疗上限、灾难与维修、路线约束、战斗消耗、旧存档兼容、百日通关，以及步行和采集动画的帧切换、落脚点与加速行为。
